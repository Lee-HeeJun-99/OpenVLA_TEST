============================================================

이 결과가 단순 domain bias 제거인지
progress-aware correction의 효과인지 확인한다.

최소 비교:

C0
No correction

C1
Global mean Real→Sim shift

C2
Episode-independent progress-conditioned shift
(current method)

C3
Phase-conditioned shift

C4
Progress + phase conditioned shift
(데이터 수가 충분할 경우)

C5
Shuffled progress shift

C6
Random matched-norm shift

C7
Wrong-direction shift
가능하면 Real→Sim이 아닌 반대 방향 또는 sign-flipped control

모든 correction은 test episode leakage가 없도록 한다.

기본:
Leave-One-Episode-Out.

각 correction에 대해:

Representation Gap
Action Gap
worsened frame count
variance
pairwise structure
collapse indicator

를 계산한다.

특히 shuffled/random control이 중요하다.

만약 random correction도 비슷하게 Action Gap을 줄이면
현재 correction의 의미를 재검토해야 한다.

============================================================
6. PHASE D — Policy-Relevant Direction Analysis
============================================================

RQ:

"Real→Sim representation difference 중 어떤 방향이 실제 action에 영향을 주는가?"

대상 우선순위:

1. action_hidden_states.input
2. projector.output
3. vision_backbone.output

action_head.output은 sanity check 용도로만 사용한다.

------------------------------------------------------------
6.1 Directional perturbation
------------------------------------------------------------

각 paired sample에서:

delta_RS = z_sim - z_real

을 정의한다.

다음 perturbation을 비교한다.

z_real + alpha * delta_RS

alpha 예:

0
0.25
0.5
0.75
1.0

필요하면 작은 범위에서 negative alpha도 추가한다.

각 alpha에서 action head 또는 downstream policy를 실행하여

Delta action

을 계산한다.

목적:

Real→Sim direction을 따라 이동할수록
Sim action에 가까워지는지 확인.

------------------------------------------------------------
6.2 Random direction control
------------------------------------------------------------

delta_RS와 동일 norm을 가지는 random direction을 생성한다.

동일 alpha perturbation을 적용한다.

Real→Sim direction과 random direction의
Action Gap reduction을 비교한다.

------------------------------------------------------------
6.3 Orthogonal control
------------------------------------------------------------

가능하면 delta_RS와 직교하는 random direction을 생성한다.

동일 norm perturbation을 적용한다.

이를 통해 단순 perturbation magnitude가 아니라
direction 자체의 policy relevance를 평가한다.

------------------------------------------------------------
6.4 Local sensitivity
------------------------------------------------------------

가능하면 action_hidden에 대해 local directional sensitivity를 계산한다.

예:

||Policy(z + epsilon*v) - Policy(z)|| / epsilon

v 후보:

Real→Sim direction
random direction
orthogonal direction

gradient/Jacobian-vector product가 구현상 가능하면 사용한다.

단 전체 Jacobian을 무리하게 계산할 필요는 없다.

finite difference 또는 JVP가 충분하다.

목적:

대상:

vision_backbone.output
projector.output
action_hidden_states.input
action_head.output

단순 raw L2 크기를 layer 간 직접 비교하지 않는다.

각 layer별로 normalized metrics를 사용하고:

Representation Gap ↔ Action Gap

관계를 계산한다.

전체 correlation뿐 아니라:

episode-conditioned
phase-conditioned
progress-conditioned

분석을 수행한다.

가능하면 partial correlation 또는
phase를 통제한 regression을 사용한다.

왜냐하면 현재 phase가 강한 confound이기 때문이다.

11. PHASE I — Robustness / Statistical Validation
============================================================

가능한 모든 주요 결과에 대해:

mean
std
median
p90
episode-wise result
phase-wise result

를 제공한다.

필요하면 bootstrap confidence interval을 계산한다.

correlation에는:

Pearson
Spearman

을 사용하되 sample independence 문제를 언급한다.

225 frames는 temporal correlation이 있으므로
225개의 완전히 독립 sample처럼 과장하지 않는다.

가능하면 episode bootstrap 또는 grouped bootstrap을 사용한다.

Correction comparison은 가능하면 paired statistics를 사용한다.

p-value만으로 결론을 내리지 않는다.

effect size와 실제 Action Gap reduction을 같이 보고한다.

19. 최종 판단 기준
============================================================

이번 Offline 연구가 성공적으로 끝났다고 판단하려면
단순히 "Representation Gap을 줄였다"에서 끝나면 안 된다.

최종적으로 다음 질문에 가능한 범위에서 답해야 한다.

1.
Real과 Sim의 무엇이 다른가?

2.
그 차이가 Observation Gap을 얼마나 만드는가?

3.
Observation Gap 중 무엇이 Representation에 남는가?

4.
Representation Gap 중 무엇이 Action에 영향을 주는가?

5.
Environment alignment로 policy-relevant gap을 줄일 수 있는가?

6.
Representation correction으로 Action Gap을 줄일 수 있는가?

7.
Physical alignment와 representation correction의 관계는 무엇인가?

8.
이 결과가 held-out episode에서도 유지되는가?

9.
현재 데이터로 답할 수 없는 것은 무엇인가?

최종 evidence chain:

Environment Gap
→ Observation Gap
→ Representation Gap
→ Policy-Relevant Representation Gap
→ Offline Action Gap

여기까지를 이번 작업에서 최대한 완성한다.

Real Performance는 별도 Phase로 남긴다.

============================================================
20. 지금 바로 시작
============================================================

먼저 기존 작업기록과 phase1/phase2 결과를 읽고,
이미 VERIFIED된 결과를 불필요하게 다시 처음부터 반복하지 않는다.

그 다음 현재 filesystem에서 실제로 수행 가능한 Offline experiment를 분류한다.

가능한 실험은 사용자에게 다시 허락을 묻지 말고 실행한다.

Environment alignment에서 Real physical measurement가 없어 정확한 정합이 불가능한 factor는 임의의 값을 만들지 말고,
해당 factor를 UNVERIFIED로 남기거나 sensitivity experiment로 전환한다.

실험 결과가 기존 hypothesis와 반대여도 그대로 유지한다.

모든 결과가 끝난 후에만 사용자에게:

- 무엇을 수행했는지
- 무엇이 새롭게 VERIFIED됐는지
- 기존 hypothesis 중 무엇이 지지/기각됐는지
- 아직 무엇이 UNVERIFIED인지
- Real experiment 전에 무엇이 남았는지

를 한 번에 보고한다.

계획만 작성하지 말고 지금 실제 Offline 작업을 시작하라.
