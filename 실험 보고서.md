## 1. 연구 질문

본 실험의 핵심 질문은 단순히 Real과 Sim의 이미지 또는 latent representation이 다르다는 것을 보이는 것이 아니다.

핵심 질문은 다음이다.

```text
Real과 Sim 사이에서 발생하는 Representation Gap 중
실제 downstream policy action prediction에 영향을 주는
Policy-Relevant Representation Gap은 무엇인가?
```

따라서 본 연구에서는 다음 연결고리를 검증 대상으로 삼았다.

```text
Environment / Observation Gap
        ↓
Representation Gap
        ↓
Policy-Relevant Representation Gap
        ↓
Action Gap
```

가장 중요한 해석 원칙은 다음이다.

```text
Large Representation Gap
≠
Large Policy Impact
```

그리고:

```text
Reducing Representation Gap
≠
Reducing Action Gap
```

즉, representation 전체를 많이 맞추는 것보다 policy가 실제 action을 결정할 때 민감하게 사용하는 성분을 찾고 줄이는 것이 중요하다.

이번 보고서의 결과는 기존 225 paired frame에 대한 offline vision-policy 연구 결과이다.


현재 ROS runtime의 `oftplus_h5_proprio`는 본 보고서의 주 결과에 포함하지 않는다. Architecture audit 결과, `oftplus_h5_vision`과 `oftplus_h5_proprio`는 완전히 별개의 architecture가 아니라 같은 base OFT/OpenVLA architecture에 optional proprio branch/token이 추가되는 관계다. 그러나 checkpoint, input interface, preprocessing이 다르므로 동일 policy로 취급하지 않는다.

따라서 본 보고서의 모든 Action Gap 및 correction 결과는 `oftplus_h5_vision` offline evidence로 해석한다.

## 5. Phase 4: Policy-Relevant Representation Gap

Phase 4에서는 `action_hidden_states.input`에서 Real/Sim hidden difference가 실제 action head 출력에 어떤 영향을 주는지 분석했다.

주요 비교:

| Method | Held-out | Action Gap | Representation Reduction | 해석 |
|---|---:|---:|---:|---|
| No correction | Yes | 0.370245 | 0.000000 | baseline |
| Full Real->Sim hidden delta | No | 0.000664 | 1.000000 | sanity check, deploy 불가 |
| LOO progress hidden shift | Yes | 0.072325 | 별도 | deployability-like offline correction |
| Sensitive projection | No | 0.136015 | 0.009250 | 작은 policy-sensitive 성분이 Action Gap 크게 감소 |
| Null residual | No | 0.274003 | 0.884700 | representation은 크게 줄지만 action 개선은 약함 |
| LOO top20 token correction | Yes | 0.157898 | 0.515030 | token targeting은 효과 있지만 diffuse |

가장 중요한 결과:

```text
Sensitive projection:
  Representation reduction: 0.925%
  Action Gap reduction:     63.26%

Null residual:
  Representation reduction: 88.47%
  Action Gap reduction:     25.99%
```

이 결과는 본 연구의 핵심 가설을 직접 지지한다.

```text
Representation Gap magnitude != Policy relevance
```

전체 representation을 많이 줄이는 것보다 action-sensitive direction을 줄이는 것이 Action Gap 감소에 더 중요했다.

## 6. Phase 5: Correction Robustness 및 Held-Out 검증

Phase 5에서는 hidden correction이 단순 우연이나 overfit인지 확인하기 위해 LOO episode split과 control correction을 비교했다.

LOO correction ablation 결과:

| Correction | Action Gap |
|---|---:|
| No correction | 0.370245 |
| Global mean | 0.125657 |
| Progress | 0.072325 |
| Phase | 0.066682 |
| Progress + Phase | 0.061829 |
| Random matched-norm | 0.367535 |
| Shuffled progress | 0.130975 |
| Wrong direction | 0.485313 |

해석:

- Progress/phase-conditioned correction은 random/wrong-direction control보다 훨씬 좋다.
- Wrong-direction은 오히려 Action Gap을 baseline보다 키운다.
- correction 방향성이 중요하며, norm만 맞춘다고 action이 개선되지 않는다.

Gate generalization:

| Gate | Action Gap | Worsened Frames |
|---|---:|---:|
| progress_all | 0.072325 | 33 |
| phase_gate_train | 0.072086 | 14 |
| progress_gate_lambda | 0.073059 | 2 |
| progress_gate_zero_worse | 0.081698 | 1 |
| oracle | 0.071488 | 0 |

해석:

- unconditional correction은 평균 gap을 크게 줄이지만 일부 frame을 악화시킨다.
- gating은 평균 성능을 거의 유지하면서 worsened frame을 줄인다.
- 특히 deployment 관점에서는 progress/phase gate가 더 안전한 후보가 될 수 있다.

Low-rank sensitive basis:

```text
Action-hidden low-rank sensitive basis, k=128:
Action Gap: 0.006676
Representation reduction: 0.030669
```

이 결과는 작은 policy-sensitive subspace가 Action Gap 대부분을 설명할 수 있음을 강하게 시사한다. 단, 이 방법은 paired Sim hidden 정보를 사용하므로 runtime deployable correction은 아니다.

## 7. Phase 6: Environment / Observation Factor Attribution

Phase 6의 질문은 다음이다.

```text
어떤 controllable observation/environment factor가
policy-relevant representation difference를 만들고
최종 Action Gap에 영향을 주는가?
```

중요하게도 Phase 6에서는 단순 Vision Gap 감소가 아니라 최종 action output까지 full-forward로 확인했다.

### 7.1 Preprocessing Ablation

Baseline:

```text
P0_current_paired_image
Action Gap: 0.370203
```

가장 강한 factor:

```text
P4_letterbox_224
Action Gap: 0.101993
Action Gap reduction: 72.45%
Hidden Gap reduction: 32.08%
Vision Gap reduction: 23.42%
Gripper Gap: 0.315337 -> 0.120110
```

Center crop 계열도 강한 효과를 보였다.

```text
P2_center_crop_square_resize_224: Action reduction 59.70%
P3_center_crop_0p875_resize_224:  Action reduction 51.24%
P1_resize_224_direct:             Action reduction 0.26%
```

해석:

- 단순 resize는 거의 효과가 없다.
- crop/letterbox처럼 image geometry와 object/framing을 바꾸는 preprocessing이 Action Gap에 크게 영향을 준다.
- 현재 dataset에서는 gripper component가 Action Gap의 큰 부분을 차지한다.

### 7.2 Photometric Ablation

Photometric/statistic matching은 observation metric을 크게 개선했지만 policy output은 개선하지 못했다.

```text
P5_brightness_match_sim_to_real:
  Observation MSE: 0.026690
  Action Gap:     0.376782
  Action change:  -1.78%

P6_contrast_match_sim_to_real:
  Action Gap:     0.371546
  Action change:  -0.36%
```

중요한 대조:

```text
P5 brightness:
  observation metric best
  action worsens

P4 letterbox:
  observation MSE not best
  action improves 72.45%
```

따라서 image statistic alignment는 policy alignment를 보장하지 않는다.

### 7.3 Camera Image-Space Sensitivity

Camera 실험은 calibrated camera alignment가 아니라 Sim image에 shift/zoom/rotation을 가한 controlled image-space sensitivity다.

Best camera condition:

```text
C2_sim_shift_right_24px
Action Gap: 0.335682
Action Gap reduction: 9.33%
Hidden Gap reduction: 2.81%
Vision Gap reduction: -1.06%
```

중요한 대조:

```text
C1_sim_shift_left_24px:
  Observation MSE: 0.085792
  Action Gap:     0.382553
  Action change:  -3.34%

C2_sim_shift_right_24px:
  Observation MSE: 0.095760
  Action Gap:     0.335682
  Action change:  +9.33%
```

즉, C1은 observation MSE를 개선하지만 action을 악화시키고, C2는 observation MSE를 악화시키지만 action을 개선한다.

Policy-sensitive projection:

```text
C0 sensitive energy: 67.585359
C2 sensitive energy: 62.328616
C2 sensitive energy reduction: 7.78%
C2 action reduction: 9.33%
```

해석:

- camera-like perturbation에서도 단순 pixel/statistical metric보다 policy-sensitive energy가 action 방향과 더 잘 맞는다.
- 그러나 C2 효과는 P4 preprocessing 효과보다 훨씬 작다.

### 7.4 Combined P4 + C2

P4와 C2가 additive한지 확인하기 위해 combined full-forward를 수행했다.

```text
K0_P4_letterbox:
  Action Gap:       0.101274
  Hidden Gap:       187.747536
  Sensitive Energy: 29.077619
  Observation MSE:  0.048681

K1_P4_letterbox_C2_shift_right_24px:
  Action Gap:       0.130148
  Hidden Gap:       200.902644
  Sensitive Energy: 37.908585
  Observation MSE:  0.072586
```

P4 위에 C2를 추가하면:

```text
Action Gap:       28.51% 악화
Hidden Gap:       7.01% 악화
Sensitive Energy: 30.37% 악화
Vision Gap:       12.70% 악화
```

결론:

- C2는 original image 조건에서는 도움이 됐지만 P4와 결합하면 악화된다.
- environment/preprocessing factor의 효과는 additive하지 않고 condition-dependent하다.
- 따라서 좋은 single-factor를 무작정 합치는 방식은 위험하다.

### 7.5 Environment Alignment x Hidden Correction

P4 preprocessing과 hidden correction이 complementary한지 확인했다.

```text
Original P0 raw Action Gap: 0.370203
Original P0 + progress/phase hidden correction: 0.061464

P4 letterbox raw Action Gap: 0.101993
P4 letterbox + P4-specific hidden correction: 0.072575
P4 letterbox + P0-trained correction transfer: 0.090531
```

해석:

- Hidden correction은 P0에서 매우 강하다.
- P4는 raw 상태에서 이미 Action Gap을 많이 줄인다.
- P4-specific correction은 P4를 추가로 개선한다.
- P0-trained correction을 P4에 transfer하면 개선은 약하고 representation gap은 오히려 증가한다.
- correction은 environment/preprocessing condition에 따라 calibration이 달라진다.

Sensitive energy:

```text
P0 raw:                  67.585359
P0 + correction:         36.784414

P4 raw:                  29.082477
P4 + P4 correction:      21.531851
P4 + P0 correction:      56.653547
```

이 결과도 policy-sensitive residual을 줄이는 변화가 action 개선과 더 잘 맞는다는 해석을 강화한다.

### 7.6 Held-Out Episode Condition Selection

조건 선택을 같은 데이터에서만 한 것이 아닌지 확인하기 위해 leave-one-episode-out selection을 수행했다.

```text
Train action-min selection:
  selected P4 in 5/5 folds
  held-out action gap: 0.102457
  held-out action reduction: 72.65%

Train hidden-min selection:
  selected P4 in 5/5 folds
  held-out action gap: 0.102457

Train observation-MSE-min selection:
  selected P5 brightness in 5/5 folds
  held-out action gap: 0.378114
  held-out action change: -1.85%
```

결론:

- action/hidden 기준 선택은 held-out episode에서도 P4를 선택하고 성능을 유지한다.
- observation MSE 기준 선택은 P5를 선택하지만 held-out action을 악화시킨다.
- 이는 observation metric만으로 policy-relevant alignment를 고르면 실패할 수 있음을 보여준다.

## 9. 핵심 결론

### 결론 1. Representation Gap 자체는 최종 기여가 아니다.

Real/Sim representation이 다른 것은 확인되었지만, 그 차이 전체가 action에 중요한 것은 아니었다.

특히:

```text
Sensitive projection:
  representation reduction 매우 작음
  action reduction 큼

Null residual:
  representation reduction 큼
  action reduction 작음
```

이 결과는 policy-relevant representation gap이라는 개념을 지지한다.

### 결론 2. Action-sensitive hidden structure가 중요하다.

`action_hidden_states.input`에서의 progress/phase correction, sensitive projection, low-rank sensitive basis 모두 최종 action gap을 크게 줄였다.

특히 progress+phase correction은 held-out episode 기준:

```text
0.370245 -> 0.061829
```

로 감소했다.

### 결론 3. Observation metric 최적화는 policy 최적화가 아니다.

P5 brightness는 observation MSE를 가장 크게 줄였지만 action은 악화시켰다.

반대로 P4 letterbox는 observation MSE 기준 최선은 아니지만 Action Gap을 가장 크게 줄였다.

따라서 Sim-to-Real alignment는 global image similarity가 아니라 policy-sensitive effect를 기준으로 평가해야 한다.

### 결론 4. Environment factor 효과는 non-additive이고 condition-dependent다.

C2 right shift는 original condition에서는 Action Gap을 줄였지만 P4 위에 결합하면 오히려 악화됐다.

이는 environment factor를 하나씩 좋다고 판단한 뒤 무조건 결합하는 방식이 위험하다는 것을 보여준다.

### 결론 5. 현재 결과는 offline Level-2 evidence다.

본 보고서의 결과는 final action prediction 차이를 줄였다는 offline action-level evidence다.

아직 다음은 주장하지 않는다.

```text
Real robot task success improved.
Current ROS proprio policy improved.
Camera/lighting/geometry is the physical cause.
Unseen layout/generalization is proven.
```

## 10. 한계

1. Real robot closed-loop performance는 아직 검증하지 않았다.
2. 현재 ROS deployment는 `oftplus_h5_proprio`이며, 본 분석의 `oftplus_h5_vision`과 checkpoint/input/preprocessing이 다르다.
3. Real physical camera intrinsic/extrinsic, table geometry, coordinate frame은 완전히 VERIFIED가 아니다.
4. Camera 실험은 image-space sensitivity이며 calibrated camera alignment가 아니다.
5. 현재 dataset은 5 episodes / 225 frames로 작고, temporal correlation이 있다.
6. Leave-one-episode-out은 held-out episode 검증일 뿐 unseen layout/trajectory generalization은 아니다.
7. Sensitive basis는 policy relevance proxy이며 causal neuron identity가 아니다.

## 11. 다음 실험 제안

### 11.1 Deployment track 분리

현재 ROS real deployment와 연결하려면 별도 track이 필요하다.

필수 확인:

```text
oftplus_h5_proprio checkpoint
proprio synchronization
ROS preprocessing
instruction
action normalization
runtime action adapter
```

기존 `oftplus_h5_vision` 결과를 ROS proprio policy 결과로 재해석하지 않는다.

### 11.2 Runtime preprocessing audit

P4 letterbox가 offline에서 가장 강했지만, 이를 바로 runtime에 적용하면 policy training preprocess와 runtime preprocess semantics가 바뀔 수 있다.

따라서 다음을 먼저 확인해야 한다.

```text
현재 ROS image path
current crop/resize
training preprocess와 runtime preprocess 차이
P4 적용 시 image tensor가 policy training 분포에 가까워지는지
P4 적용 시 real robot action command가 안전한지
```

### 11.3 추가 dataset

현재 5 episodes만으로는 broad generalization을 주장할 수 없다.

다음 데이터가 필요하다.

```text
unseen orange cube positions
unseen trajectories
different distractor layouts
possibly different camera/lighting conditions
```

### 11.4 Real robot 검증 전 단계

Real robot을 움직이기 전에 shadow mode를 권장한다.

```text
Real robot executes reference trajectory
VLA prediction is logged only
No VLA command is sent to robot
Compare reference action vs predicted action
Check latency/safety/failure frames
```

## 13. 최종 요약

이번 실험은 Real/Sim representation gap을 단순히 측정하는 단계에서 더 나아가, 그 중 실제 policy action에 영향을 주는 성분을 분리해보려는 offline 연구다.

현재까지의 가장 강한 evidence는 다음이다.

```text
1. Real/Sim representation gap은 존재한다.
2. 하지만 전체 representation gap 크기만으로 Action Gap을 설명할 수 없다.
3. action_hidden_states.input의 작은 policy-sensitive component가 Action Gap에 큰 영향을 준다.
4. progress/phase hidden correction은 LOO episode 기준 Action Gap을 크게 줄인다.
5. preprocessing factor, 특히 P4 letterbox, 는 policy-sensitive hidden/action gap을 크게 줄인다.
6. photometric image-stat matching은 observation metric을 개선해도 action을 개선하지 못했다.
7. camera-like perturbation 효과는 작고 condition-dependent하다.
8. 좋은 single factor를 결합한다고 항상 좋아지지 않는다.
```

따라서 본 연구의 현재 결론은 다음과 같이 정리할 수 있다.

```text
Sim-to-Real alignment는 global visual similarity나 global representation similarity를 목표로 삼기보다,
policy가 실제 action을 결정할 때 민감하게 사용하는 representation component를 기준으로 평가하고 조정해야 한다.
```
